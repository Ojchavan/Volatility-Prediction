# Volatility Prediction

PyTorch notebook for forecasting asset volatility from historical market data.

## What it covers

- Feature engineering on return series
- Sequence models in PyTorch
- Train / validation splits and evaluation plots

## Stack

Python · Jupyter · PyTorch · pandas · NumPy

## Open the notebook

```bash
git clone https://github.com/Ojchavan/Volatility-Prediction.git
cd Volatility-Prediction
jupyter notebook Volatility_Prediction.ipynb
```
